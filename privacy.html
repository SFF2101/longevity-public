Longevity Drive Privacy Policy

Last updated: 11 November 2026

Longevity Drive is a private, non-commercial application used by its operator to archive personal health records and derived measurement datasets. This public website contains no health records.

Google user data accessed

The application requests only the Google Drive drive.file OAuth permission. It may access files and folders it creates or which the account owner explicitly makes available to the application. It does not request broad access to unrelated Google Drive content.

Purpose and use

Authorised Google Drive access is used exclusively to create an application-managed archive, upload local files, check remote file existence, and verify integrity by downloading or comparing content. This application does not use Google data for advertising, profiling, or model training.

Stored data and security

When the archival service is deployed, it is intended to store personal health archives and derived datasets within the owner's own Google Drive account. OAuth credentials are to be held in private runtime storage, not in this public repository or website. Client-side encryption for sensitive records is planned but is not yet deployed or verified. The initial connection test uses only non-sensitive synthetic data.

Sharing and retention

The application is not offered to the public. Data are not sold, provided to advertisers, or intentionally shared with unrelated third parties. Google provides the underlying storage service according to the account owner's Google terms and settings. Archived files remain until the owner deletes them or explicitly authorises a retention action. Local originals are not deleted automatically by this application.

Revocation

The account owner can revoke the application's authorisation through Google Account security settings and can delete application-created files from Google Drive.

Contact

The application's operator can be contacted through the support email shown on the Google OAuth consent screen.
